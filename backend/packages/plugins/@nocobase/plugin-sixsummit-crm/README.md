# @nocobase/plugin-sixsummit-crm

Native NocoBase calling workspace and sales analytics for 6ixSummit Labs. Provides authenticated `six_crm` actions, transactional disposition changes, caller ownership, append-only history and a shared v1/v2 client screen.

Owned source lives here; the backend link script copies it into the pinned NocoBase checkout for development and builds. See [backend setup and API documentation](../../../../README.md).
